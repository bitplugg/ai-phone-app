📦 Installation

  1. Download the APK from Releases
  2. Enable "Install from unknown sources" in Android Settings
  3. Open the APK file and install
  4. Enjoy!

Via ADB

adb install app-debug.apk

⚙️ Configuration

Ollama (Local)

  1. Install Ollama on your PC
  2. Run ollama serve on PC
  3. Get PC's local IP (e.g., 192.168.1.100)
  4. Enter IP in app settings: http://192.168.1.100:11434

Cloud AI

Get API key from OpenAI or DeepSeek and enter in app settings.
