📦 Installation

  1. Download the APK from Releases
  2. Enable "Install from unknown sources" in Android Settings → Security
  3. Open the APK file and install
  4. Enjoy your AI assistant! 🎉

Via ADB

adb install app-debug.apk

⚙️ Configuration

🤖 Ollama (Local AI)

  1. Install Ollama on your PC
  2. Run ollama serve on your PC
  3. Get your PC's local IP (e.g., 192.168.1.100)
  4. Enter IP in app settings: http://192.168.1.100:11434
  5. Select WiFi mode in app

☁️ Cloud AI (OpenAI / DeepSeek)

Get API key from OpenAI or DeepSeek, enter in app settings.

❓ FAQ

🔒 Is my data safe?
Yes! When using Ollama locally, all conversations stay on your network. Cloud APIs use your API key securely.
📡 Can I use it without WiFi?
Yes! Switch to Cloud AI mode (OpenAI or DeepSeek) to use AI anywhere with internet.
🔋 Does it drain battery?
Minimal! The app only uses battery when actively communicating with AI. Ollama runs on your PC, not the phone.
🌐 What models are supported?
Locally: Llama 3, Mistral, CodeLlama and more. Cloud: GPT-4, GPT-3.5, DeepSeek V3.
💰 Is it really free?
Yes! 100% free and open source. You only pay for cloud API calls (OpenAI/DeepSeek) if you use them.
